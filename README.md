## What is IVERI AI Agent?

**IVERI AI Agent** is a sovereign personal and industrial AI agent workbench combining:
- **Claude Code & Devin Capabilities**: Direct filesystem editing, terminal execution, AST parsing, and autonomous tool calling.
- **NotebookLLM-Style Document Intelligence**: Layout-aware parsing of 500+ page technical manuals and PDFs with table geometry preservation via OpenDataLoader.
- **Claude & Grok Style Artifacts**: Interactive side-panel for live code execution, statutory memos, SVG diagrams, and HTML widgets.
- **Cyberpunk Sovereign Telemetry**: Real-time 1Hz socket monitoring certifying 0-byte external network exfiltration for defense, PSU, and refinery compliance (MRPL Problem Statement 26117).
- **Fast Multimodal Edge AI**: SmolVLM-256M local vision (~500MB VRAM footprint) and KittenTTS offline speech synthesis.

## Quickstart

### 1. Windows 1-Click Launch

```cmd
:: Run sovereign hardware & air-gap diagnostics
iveri.bat doctor

:: Start interactive sovereign REPL
iveri.bat chat

:: Launch Sovereign Web Dashboard on http://127.0.0.1:9119
iveri.bat web

:: Run Golden Demo on repository PDF books
iveri.bat demo
```

### 2. PowerShell Launch

```powershell
.\iveri.ps1 doctor
.\iveri.ps1 chat
.\iveri.ps1 web
.\iveri.ps1 demo
```

### 3. Air-Gapped Docker Deployment

```bash
docker compose -f docker-compose.iveri.yml up -d
```
