## 🌍 The Vision: Sovereign Intelligence for Everyone

**IVERI AI Agent** is not built only for massive industrial plants, defense agencies, or billion-dollar refineries. **IVERI is built for every single human being on planet Earth.**

- **For Students & Researchers**: Read, cross-examine, and synthesize thousands of pages of academic textbooks (like Russell & Norvig or deep research papers) with layout-aware table extraction and zero subscription fees.
- **For Coders, Hackers & Developers**: A Devin-class autonomous software engineering workbench that navigates repositories, writes full codebases, runs terminal commands, self-heals compiler bugs, and renders Claude/Grok-style interactive Artifacts.
- **For Writers, Creators & Thinkers**: Generate structured books, statutory memos, executive deliverables (`.docx`), speech (`.wav`), and SVG graphics locally on hardware you already own.
- **For Enterprises, Hospitals & Refineries**: Guarantee strict air-gapped zero-data-exfiltration compliance (e.g. MRPL Problem Statement 26117) with kernel-level socket interception and live cryptographic audit proofs.
- **For Privacy Advocates**: No telemetry sent to big tech corporations. No cloud snooping. Your thoughts, files, and intellectual property remain 100% sovereign on your local disk.

## ⚡ Key Architectural Pillars

| Capability | What It Does | Why It Dominates |
| :--- | :--- | :--- |
| **Autonomous Coding (Devin / Claude Code)** | Edits codebases, runs tests, fixes bugs, and orchestrates multi-file refactors. | Operates directly on local files with zero rate-limits. |
| **Document Intelligence (NotebookLLM++)** | Layout-aware streaming PDF parser handling 500+ page technical books with table geometry preservation. | Hybrid sub-second retrieval over local SQLite WAL. |
| **Artifacts Subsystem (Claude / Grok)** | Extracts `<iveri_artifact>` blocks into a dedicated interactive side-drawer with live previews and versioning. | Preserves chat context; exports `.docx`, HTML, SVG, and code. |
| **Cyberpunk Sovereign Telemetry** | Kernel socket-level interception blocking all external network egress with `ConnectionRefusedError`. | Live 1Hz UI gauges and cryptographic HMAC audit certificates. |
| **Fast Local Multimodal Engine** | SmolVLM-256M local vision (~500MB VRAM footprint) + KittenTTS offline speech generation. | Triage diagrams, images, and audio on entry-level laptops. |
| **7 Cognitive Memory Systems** | Episodic, semantic, procedural, prospective, retrieval, working, and parametric memory. | Learns from past failures and persists knowledge across sessions. |

## 🚀 Quickstart Guide

### 1. Windows 1-Click Launch
Double-click `iveri.bat` or run:
```cmd
:: Run sovereign hardware & air-gap diagnostics
iveri.bat doctor

:: Launch interactive sovereign REPL
iveri.bat chat

:: Start Sovereign Web Dashboard & Telemetry on http://127.0.0.1:9119
iveri.bat web

:: Execute Golden Demo across repository PDF books
iveri.bat demo
```

### 2. PowerShell Launch
```powershell
.\iveri.ps1 doctor
.\iveri.ps1 chat
.\iveri.ps1 web
.\iveri.ps1 demo
```

### 3. Air-Gapped Docker Deployment
```bash
# Start IVERI Sovereign Agent + Local Ollama daemon
docker compose -f docker-compose.iveri.yml up -d

# Open Sovereign Dashboard
http://localhost:9119
```
